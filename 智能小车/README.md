# 智能小车（四轮红外循迹小车）

基于 **STM32F103C8T6 + 标准外设库** 的四轮差速小车：两片 TB6612 分别驱动左右两侧的前、后电机，五路 TCRT5000 红外循迹模块实时检测黑线位置并分级差速纠偏，OLED 实时显示车速与循迹状态。

## 功能特性

- **四轮驱动**：两片 TB6612，每片的 A/B 两通道分别接同侧前、后电机；同侧两通道的方向引脚与 PWM 引脚并联，四个电机两两同步动作
- **调速**：TIM2 四通道 PWM（20kHz，PA0~PA3），实际使用 CH1/CH2 控制左右侧速度，CH3/CH4 备用（可扩展舵机等）
- 速度范围 **-100~100**，负值反转；方向由 PA4~PA7 控制
- **五路红外循迹**：黑线位置分级判定 + 差速纠偏（居中直行 / 小幅修正 / 大幅修正）
- **OLED 实时显示**：左右侧电机速度、五路探头压线状态、黑线偏差值、运行状态

## 硬件连接

| 模块 | 接线 |
|---|---|
| TB6612 #1（左侧：左前 + 左后） | AIN1+BIN1 → PA4，AIN2+BIN2 → PA5，PWMA+PWMB → PA0（TIM2_CH1），STBY → VCC |
| TB6612 #2（右侧：右前 + 右后） | AIN1+BIN1 → PA6，AIN2+BIN2 → PA7，PWMA+PWMB → PA1（TIM2_CH2），STBY → VCC |
| 五路 TCRT5000 循迹模块 | **镜像接线**：OUT1(物理最左)→PA12、OUT2→PA11、OUT3→PA10、OUT4→PA9、OUT5(物理最右)→PA8，VCC 接 5V（或 3.3V），GND 共地 |
| OLED（软件 I2C） | SCL → PB8，SDA → PB9 |
| 按键 | PB1、PB11 |

## 循迹逻辑

五个探头沿行驶方向从左到右编号 1~5，正常行驶时仅 3 号正对黑线：

| 压线探头 | 判定 | 左侧电机 | 右侧电机 |
|---|---|---|---|
| 仅 3 号 | 黑线居中，直行 | 基准速度 | 基准速度 |
| 2 号 | 小幅右偏航，小幅左转修正 | 基准 + 15 | 基准 − 15 |
| 1 号 | 大幅右偏航，大幅左转修正 | 基准 + 30 | 基准 − 30 |
| 4 号 | 小幅左偏航，小幅右转修正 | 基准 − 15 | 基准 + 15 |
| 5 号 | 大幅左偏航，大幅右转修正 | 基准 − 30 | 基准 + 30 |

边界处理：

- 五路全黑（十字路口）→ 按直行通过
- 五路全白（急弯丢线）→ 保持上一次输出，沿原修正方向找线
- 多路同时压线（过渡状态）→ 按最外侧探头优先处理

## 软件结构

- `Hardware/Motor1.c`、`Motor2.c`：左右两侧 TB6612 驱动模块（初始化 + `SetSpeed`）
- `Hardware/PWM.c`：TIM2 四通道 PWM 底层
- `Hardware/Tracking.c`：五路循迹驱动（状态读取 + 偏差计算）
- `Hardware/OLED.c`：屏显驱动（软件 I2C）
- `System/Delay.c`、`Timer.c`：延时 / 定时中断
- `User/main.c`：循迹控制逻辑（`Track_Follow`）与 OLED 显示

## 可调参数（User/main.c）

- `Speed`：直行基准速度（0~100）
- `TRACK_SMALL_ADJ` / `TRACK_LARGE_ADJ`：小幅 / 大幅修正量
- `Hardware/Tracking.h` 中的 `TRACKING_DO_BLACK`：黑线电平极性。本模块实测**黑线输出低电平、白色输出高电平**，已配置为 0（与 `TRACKING_DO_WHITE` 配套取反）；更换模块若极性相反，两宏对调即可

## 踩过的坑

- **TIM2 只能用于一个用途**：定时中断（Timer.c）与 PWM 输出冲突，二者只能用其一
- **LED 模块引脚冲突**：LED.c 使用 PA1/PA2，与电机 PWM 冲突，电机程序中不要调用 `LED_Init()`
- TB6612 的 **STBY 必须拉高**，且驱动板与单片机必须**共地**，否则电机不转
- 电机转向与预期相反时，对调该电机两根线即可（代码不用改）
- 循迹状态整体相反时，改 `TRACKING_DO_BLACK` 宏，而不是逐路对调接线
- **循迹极性接反的表现**：无论黑线偏哪一侧，输出的都是同一组差速（实测无论压 2/3/4/5 号探头，左右速度都是 80/20）。原因：代码从最外侧探头开始逐位找"值为 1（黑线）"的位，极性反了就永远先命中第一个白色探头。用万用表或 OLED 显示标定一次黑/白电平即可确认
- **电机驱动模块左右接反的表现**：直行完全正常，但修正方向全部相反（要左转它右转）。本仓库用**循迹接线镜像**补偿（OUT1→PA12……OUT5→PA8），因此代码坐标与物理左右相反，OLED 的 `IR:` 显示和 `E:` 偏差值也是镜像的（挡物理最左探头显示 `00001`）。若日后把电机接线改正，需把五根 OUT 线换回正序（OUT1→PA8……OUT5→PA12），否则方向会再次镜像回去
