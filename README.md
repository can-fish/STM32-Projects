# STM32 项目集

基于 **STM32F103C8T6（Cortex-M3）+ 标准外设库（StdPeriph）** 的三个入门项目。

## 项目列表

| 项目 | 简介 | 主要技术点 |
|---|---|---|
| [智能小车](./智能小车/) | 四电机小车底盘，OLED 实时显示轮速与状态 | TB6612 ×2、TIM2 双通道 PWM 调速、按键控制 |
| [温控智能风扇](./温控智能风扇/) | NTC 测温自动调速风扇，支持手动模式 | ADC 采集、B 值公式换算温度、PWM、旋转编码器 |
| [湿温度检测装置](./湿温度检测装置/) | 温湿度实时显示，超限声光报警 | DHT11 单总线时序、OLED 汉字显示、蜂鸣器报警 |

## 开发环境

- IDE：Keil MDK 5
- 库：STM32F10x 标准外设库（StdPeriph V3.5.0）
- 芯片：STM32F103C8T6

## 如何编译

用 Keil 打开各项目目录下的 `Project.uvprojx`（湿温度项目为 `project.uvprojx`），编译后烧录即可。编译中间产物（`Objects/`、`Listings/` 等）已在 `.gitignore` 中排除。
