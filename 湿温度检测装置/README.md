# 湿温度检测装置

DHT11 采集温湿度，OLED 中文界面实时显示，超出安全范围时蜂鸣器鸣叫 + LED 声光报警。

## 功能

- DHT11 单总线时序驱动，读取温度 / 湿度
- OLED 中文界面：`温度：xx℃` / `湿度：xxRH`
- 超限报警判断：温度 <20℃ 或 >30℃，湿度 <40% 或 >85% 时
  - 蜂鸣器（PB1）鸣叫
  - 报警 LED（PB12/PB15）点亮指示
- 采集间隔 500ms

## 硬件连接

| 模块 | 引脚 |
|---|---|
| DHT11 | 接线见 `Hardware/dht11.c` |
| 蜂鸣器 | PB1（低电平鸣叫） |
| 报警 LED | PB12 / PB15 |
